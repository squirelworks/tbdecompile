# coursemanager viewer

Early attempt at a ToolBook-style lesson viewer. Lived under `coursemanager/viewer4/` on the `squirelworks.github.io` archive site.

It loads pre-converted lesson JSON from `lessonshells/` (catalog + per-course files) and renders a page-by-page reader with quiz handling, help jumps, and a developer page picker. It does not parse TBK files.

The live course XML/JSON data stayed on the website and is being removed. Foolbook is the reader. This is kept here only as one of the early viewer experiments (alongside `maybe/`, `viewer/`, `runtime/`).
