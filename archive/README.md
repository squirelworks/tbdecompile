# Archive

Old work. The record is `record/`. When a sheet and the record disagree, the record wins. Foolbook is the reader. Nothing in this folder is a second one.

## Efforts

| Path | What it was |
|---|---|
| `efforts/viewer` | One page from a book XML file. No OpenScript. |
| `efforts/viewer2` | A catalog in front of that page frame. |
| `efforts/viewer3` | The same catalog, left so viewer2 would not be edited again. |
| `efforts/maybe` | A viewer that loads system shells and lesson JSON. It does not parse a TBK. `Maybe-Finished.zip` and `Maybe2-Finished.zip` are the packed copies. Maybe3 and Maybe4 were empty directories. |
| `efforts/runtime` | The clean-room reader that became Foolbook. Python. |
| `efforts/runtime_cpp` | The same idea in C++, drawing a few pages to SVG. |
| `efforts/sbk` | System-book handlers copied out as JavaScript. |
| `efforts/bmpproxy` | A 16-bit stand-in for `TB80BMP.DLL` that logged two ordinals. |
| `efforts/nedllhost` | A small binder for an NE DLL. The pass logs stayed with TBpipeline. |
| `efforts/nehost` | A pointer. The host is `tbpipeline/tbpipeline_bf/nehost/`. |
| `efforts/debugging` | SoftICE field notes, closed 11 October 2026. |
