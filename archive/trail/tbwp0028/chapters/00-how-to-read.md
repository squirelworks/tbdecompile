## Grades

| Grade | Meaning |
|---|---|
| Known | Seen in a binary, a live trace, or a matching export. A later observation would have to contradict the evidence, not just a reading of a listing. |
| Thought | Fits the evidence and is the working model. Not yet watched end to end. |
| Conjecture | Plausible. Not tested. |
| Not true | Was a working idea. Later evidence closed it. Do not search it again. |
| Superseded | An older note still says this. The later note wins. The older path is listed so it is not reopened by accident. |

## What this record will not hold

Binary dumps, SoftICE console logs, and personal correspondence stay in the working papers. This record points at those paths. It does not copy them. Names of correspondents are masked. The correspondent already used in the public notes is JohnDoe1.

## Which older file to trust

If a note written on or before 2026-10-15 puts `CDBSENDCREATE` between file open and the first painted object, that sentence is superseded. The correction is chapter 4 and `tbworkingpapers/tbwp0025/cdbsendcreate-is-author.md`. The 2026-10-15 file `TBdecompile/20261015/00-how-toolbook-operates.md` still describes that older chain. Read it for the object layout and the painters. Do not read section 2 of that file as the runtime create path.

Absence from a Ghidra HTML export is not absence from the binary. The listings have undisassembled runs. A candidate is closed only when the disassembly or a live trace shows what the function actually does.
