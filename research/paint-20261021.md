# Paint and resources, 21 October listing

Offsets are byte offsets of the live record. The listing is the 2026-10-21 `TB80BAS.DLL.c`. One Bochs stop is named where it happened. The P310 snapshot was Instructor, Reader level.

## Button pictures

The button record's `+0x28` is a near pointer to a graphics block. Block `+0` is a version word (`0x201` or `0x202`). Bit 0 of block `+2` is `stretchGraphic` (`0x409A`).

Four slots, `0x12` bytes each:

| Picture | Property | Slot | Resource id |
|---|---|---|---|
| Normal | `0x4097` | `+0x05` | `+0x15` |
| Invert | `0x4098` | `+0x17` | `+0x27` |
| Disabled | `0x4099` | `+0x29` | `+0x39` |
| Checked | `0x409B` | `+0x3B` | `+0x4B` |

Inside a slot, `+6` is the resource type, `+8` the width, `+0xA` the height, and `+0x10` the id. `FUN_1230_18d2` tries disabled, then invert, then checked, then normal. The bounds-plus-52 guess does not match this block.

## Where the bytes are

`FUN_1028_218a` is `OBJGETHDRLONG((type + 5) * 4)`. The index is the resource type, not the id. The dword is an object reference to that type's directory.

The directory's count is at `+2`. The id table is a near pointer at `+0x0E`, 8 bytes an entry. Word 0 is the id that is searched. Words at `+2` and `+4` are the resource object. Names are a near pointer at `+0x10`.

Type 1 is a bitmap. Type 9 is a script resource, used when the script mode is 2. Type `0x13` is a shared script. `TB80BMP` does not resolve the id. `TB80FLT` is the import filter.

`FUN_1118_0820` copies the bytes. If bit 0 of the resource object's `+8` is clear, they are the near block at `+9`. If it is set, `HUGEGETDATA` reads them. The object's first word must be `0x201` for the bitmap message.

The buffer is an 8-byte prefix and then a Windows BMP. Word 0 is `0x0201`. Word 1 is `0x0001`, and the only read of it rewrites an old version-8 buffer. `BM` is at `+8`. The info header is at `+0x16`. Word 9 of the buffer is `bfOffBits`. `9e954d01.tbk` has 67 of these. The prefix dword equals `bfSize + 8` for 19 of them and is 12 bytes over for the other 48. Use `bfSize`.

A Bochs hit at live `2B9F:218A` (Ghidra `1028:218A`) fired without a repaint. The first argument was type 9. The return was `0x20000014`, an object reference, not a file offset. The key words were `0009`, `0081`, `4BE8`: type, id minus 1, file. That is a script resource, number 130, not a picture.

## Colors

`LOCKPATTERN`: `0xFD` hollow, `0xFE` solid paper, `0xFF` solid ink, `1` through `0x80` a pattern. Outside that range it is fatal. When `DAT_1630_0208` is 0, `0xFE` and `0xFF` are the white and black stock brushes.

A draw object's pattern is `+0x25`, its stroke `+0x17`, its fill `+0x1B`. A background's pattern is `+0x4B`, its second color `+0x57`, its fill `+0x5B`, its width `+0x5F`, its height `+0x61`.

## Page, scripts, groups, classes

A class 5 page holds its background as a far reference at `+0x47` / `+0x49`. Property `0x4016` asks that object for its size. This has not been matched to a byte in an on-disk page.

`FUN_10d0_12e0` selects the script. Book (class 1): mode in the low two bits of `+0x22`, word at `+0x24`. Page and background: mode `+0x30`, word `+0x2A`. An ordinary object: mode `+0x0A`, word `+0x0B`. Mode 0 is inline. Mode 2 is a type 9 resource. The shared script is a separate request, type `0x13`.

A group's count is `+0x24`. Entries at `+0x2E` are 10 bytes: the child, then its left, top, right, and bottom. No separate stream-in was found.

Class 8 is the rectangle, draw segment `0x1410`. Class `0xC` is the ellipse, segment `0x13d8`. Class `0xD` is the rounded rectangle, segment `0x13e0`, radii at `+0x28` and `+0x2A`.

The book's font table is the pointer at `+0x28`. A style run's word at `+2` is an entry pointer. The value 1 means the field's font at `+0x22`. Word 0 of the field's `+0x24` block is the style-run handle, not a character position.
